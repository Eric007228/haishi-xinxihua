# 海事知识笔记

> 个人学习项目：海事信息化建设课程资料整理与实践。
> 笔记按章节浏览，也可以搜关键词。

**怎么用：**

- 左侧目录按「栏目 → 章节」排列，点条目进入笔记页
- 页面上方搜索框输入关键词（例如"港口"），直接找到相关笔记
- 手机上打开链接同样可以阅读，不需要注册登录

## 项目内容

- 海事信息化相关课程的学习笔记与实践代码
- 课程资料（PDF）仅保留在本地，不在此仓库公开
- 笔记正文统一放在 `notes/` 文件夹，网页骨架放在根目录
