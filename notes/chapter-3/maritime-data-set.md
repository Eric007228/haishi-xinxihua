# 第 3 章 · 海事数据集

**本章关键词：** 数据 信息 知识 信息资源 海事信息 海事业务 数据集

## 3.1 数据、信息、知识

这一节的核心是三个概念和两个"加法等式"，是本章最容易考的地方。

### 1. 数据（Data）

- 对客观事物记录下来的、可以鉴别的符号。
- 形式：数字、字符、文字、图形……
- 关键点：**数据经过处理仍然是数据**，只有经过解释才有意义。

> 等式一：**数据 + 背景 = 信息**
> 同一份数据，每个人的解释可能不同（老师手写强调：解释背景不同，结论就不同）。

### 2. 信息

- 信息是数据所表达的内容；对于**同一信息**，其数据表现形式可以多种多样。
- 例子（讲义原例）：船舶的运动状态这一"信息"，可以用雷达回波、AIS 报文、VHF 语音、CCTV 视频、报警信号等多种"数据"来反映。
- 等式二：**数据 + 语义 = 信息**

### 3. 知识

- 信息接收者通过对信息的提炼和推理而获得的正确结论。
- 被人接受、处理、吸收和利用的信息；将信息转化为行动的能力。

> 等式三：**信息 + 经验 = 知识**

### 4. 三者的关系

- 数据、信息、知识像同心圆：数据在最内层，向外依次是信息、知识。
- 计算机出现后，信息被看做数据（计算机里的信息都以数据形式存在）。

### 5. 拓展：从数据到智慧的进阶链（讲义拓展页，老师手写标注"层次不同"）

| 层次 | 含义 | 讲义例子 |
|---|---|---|
| 数据 Data | 事实的记录 | 华南地区甲壳虫轿车销售额为 1200 万 |
| 信息 Information | 数据 + 语义 | 加上"甲壳虫系列产品华东地区销售额比上期减少了 25%"的背景 |
| 知识 Knowledge | 解决问题的技能（skill） | 知道销售业绩不佳可能的原因（对手促销、质量问题、宏观因素等） |
| 智能 Intelligence | 理解（understanding）与推理（reasoning） | 分析判断原因后推断下一步走向 |
| 智慧 Wisdom | 知识的选择（Selection） | 应对行动可能有多种，但战略上选择哪个行动，则又会产生新的交易数据 |

## 3.2 信息资源与信息

- **资源的定义**：人类发展中有用的、有价值的一切**物质与非物质**要素。
- 信息资源的定义：
  - 广义：人类社会信息活动中各种要素的总称（信息生产者、信息、信息技术等）。
  - 狭义：信息本身或信息内容——经过加工、整理后有意义的数据。
- 特征：价值性、稀缺性、可共享性等（> ⚠️ 待与课堂核对：手写标注的字迹没完全认清）。
- **两大重点结论（背）**：
  1. 国民经济和社会发展的三大战略资源：**能源、材料、信息**。
  2. **信息资源的开发利用是国家信息化的核心任务**；开发利用的程度是衡量国家信息化水平的一个重要标志。

## 3.3 海事（信息）数据集

### 3.3.1 海事信息的涵义

- **海事信息**：海事管理机构在履职过程中制作或者获取的、以一定形式记录、保存的信息。
- 公民、法人和其他组织依法有获取海事信息、要求公开海事信息的权利。
- **海事管理（Maritime Administration）**：海事管理机构为保障水上交通安全、防止船舶污染水域环境，依据法律法规对水上交通安全、船舶及水上设施实施监督管理，以及行政执法等行政活动的总称。

### 3.3.2 海事管理 —— 海事业务

海事业务分**对内、对外**两大块（本章重点，复习时对着分类记）：

| 划分 | 是什么 | 具体内容 |
|---|---|---|
| **对内业务** | 海事内部管理决策类业务，实现海事系统对内的管理职能 | 内部公文管理等 |
| **对外业务** | 海事机构直接实施管理相对人的业务，包括行政执法业务、行政审批和行政检查类业务 | 见下 |

对外业务的两个清单（讲义原文，个别用词待核对）：

- **行政审批类**：船舶管理、船员管理、船公司管理、船舶检验、危防管理、通航管理、航运管理、规费稽征等
- **行政执法类**：行政处罚、行政强制、规费征收等
